# Url shortener

Сервис, предоставляющий API по созданию сокращенных ссылок.
Реализован с использованием **grpc-gateway**.

Благодаря прокси, который предоставляется grpc-gateway, можно слать HTTP запросы.

## Краткая документация

1. Эндпоинт для метода POST:
    ```bash
    /v1/url/shorten
    ```
    В теле запроса ожидает параметр **original_url**. Пример:
    ```bash
    {
      "original_url": "https://example.com"
    }
    ```

2. Эндпоинт для метода GET:
    ```bash
    /v1/url/{short_url}
    ```

## Инструкция по запуску

Для удобства составлен пример .env файла (.env_example). Можно воспользоваться содержимым из него,
а можно попробовать что-нибудь поменять. После чего понадобится создать .env файл, заполнить его
удобным для себя образом и поместить его в корень проекта:

```yaml
POSTGRES_HOST=postgres # Хост с PostgreSQL
POSTGRES_PORT=5432 # Порт для PostgreSQL
POSTGRES_USER=user # Пользователь для PostgreSQL
POSTGRES_PASSWORD=password # Пароль для PostgreSQL
POSTGRES_DB=url_shortener # БД
GRPC_PORT=50051 # GRPC порт. По умолчанию, 50051
HTTP_PORT=8080 # HTTP порт. По умолчанию, 8080
STORAGE_TYPE=postgres # Тип хранилища. По умолчанию, in_memory
```

Для запуска приложения достаточно применить команду:
```bash
  docker-compose up -d
```

После чего автоматически выполнятся следующие действия:

1. Запустится контейнер с PostgreSQL
2. Импровизированный инит-контейнер запустит на контейнере с PostgreSQL миграции
3. Будет запущен контейнер с приложением, которое будет доступно на localhost на порте,
указанным в .env файле
